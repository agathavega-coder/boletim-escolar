# 📚 Portal do Aluno - Boletim Escolar

Sistema Web para visualização de boletim escolar, cálculo de médias e verificação de situação acadêmica do aluno.

## 🚀 Tecnologias Utilizadas
- **HTML5** (Semântico e Estruturado)
- **CSS3** (Grid, Flexbox, Responsividade com `@media`, Efeitos de Hover)
- **JavaScript** (Manipulação de DOM, Funções e Lógica Condicional)

## 🎯 Funcionalidades
1. **Cálculo de Média:** Calcula a média aritmética a partir das 3 notas fornecidas.
2. **Verificação de Situação:** Retorna automaticamente se o aluno está Aprovado, em Recuperação ou Reprovado.
3. **Controle de Frequência:** Atualização dos indicadores nos cards superiores.

## 📂 Como Executar
1. Clone este repositório ou baixe os arquivos.
2. Garanta a imagem `logo.png` na pasta `imagens/`.
3. Abra o arquivo `index.html` em qualquer navegador web.
